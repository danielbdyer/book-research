# a shared focal task frees spontaneity by occupying the attention that would otherwise watch the self

Viola Spolin built her improvisation games around what she named the point of concentration: a single focus-object that every player in a game solves together, so that the focal task and not the coach runs the room. The mechanism the dig recovers is attentional rather than motivational. The focal task occupies the attention that would otherwise watch the self, and once that self-watching attention is spent on the shared object, spontaneity is not exhorted into being but structurally freed. The device degrades the instant a player pulls a component back into focus and begins to watch themselves performing it.

The dig reads this as Michael Polanyi's from-to structure run as pedagogy: Spolin's point of concentration is made focal so that the self and the technique fall subsidiary and go unwatched. The artifact the dig marks as new is the directionality. Polanyi describes subsidiary attention from the inside; Spolin engineers it from outside the person by placing an object for the group to attend to. For a book read alone the device is only partly portable, because a page can hand a reader a task but loses the field of co-present others also concentrating on it, so the reader's self-watching returns faster than it does in a room.
