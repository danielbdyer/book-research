# which forms of participation should be delegated and which should remain deliberately lived

The reframe holds open which forms of participation should be delegated and which should remain deliberately lived. The question sharpens because an external system can now perform activities that were once constitutive of a person's own participation — it can remember, synthesize, interpret, generate, critique, research, structure, and converse. Delegating some of these frees a person for others; delegating the ones through which a person experiences themselves as an author hollows out the very experience the delegation was meant to serve. The book locates its deepest danger exactly here, in outsourcing the activities that make a person feel like an agent. The question is not answered by a rule, because the line falls differently for different acts and different people, and the author met it not as theory but as event: he discovered the problem while using the technology to write the book about the problem.
