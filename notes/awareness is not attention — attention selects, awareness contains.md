# awareness is not attention — attention selects, awareness contains

The book draws a line between attention and awareness and treats awareness as the more basic of the two. Attention is selective: it isolates and points at a single object of experience, saying in effect "I am looking here." Awareness is wider and holds attention inside it, because it also registers a second thing — the noticing that one is attending at all, "I notice that I am looking here." On this account awareness is not a sharper or broader attention but a different capacity, one that contains both the object attended to and the reflexive fact of the looking. The distinction is put to work on facilitation: a facilitator has to perceive not only what a participant attends to but the surrounding field in which the attending happens.
