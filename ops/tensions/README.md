# Operational tensions

This directory holds operational tensions — places where the vault contradicts its own methodology — one file each, per the routing table in `CLAUDE.md`. Doctrinal tensions (content of the book) are claims in `notes/`, listed at `notes/tensions.md`; the two are never mixed.

The file listing beside this README carries the current count, and this README does not repeat it: an earlier version asserted "zero operational tensions currently exist" as a standing fact, went stale the day the first tension arrived, and then argued with the correction appended beneath it (audit, 2026-08-06). The contract is this. An empty directory apart from this file is the healthy state, not an omission. Each tension is one file, created when the contradiction is found and removed when the contradiction is resolved, with the resolution recorded where it happened. The session-start hook counts the files at every start and recommends /rethink at five.

This file exists so the directory survives in git — its references across `CLAUDE.md`, `notes/tensions.md`, `ops/derivation.md`, and the methodology index resolve, and the hook's count reads a real directory. The decision is indexed in `ops/decisions.md`.
