# Operational tensions

This directory holds operational tensions — places where the vault contradicts its own methodology — one file each, per the routing table in `CLAUDE.md`. Doctrinal tensions (content of the book) are claims in `notes/`, listed at `notes/tensions.md`; the two are never mixed.

The directory being empty apart from this file means zero operational tensions currently exist, which is the healthy state and not an omission. This file exists so the directory survives in git — its eight references across `CLAUDE.md`, `notes/tensions.md`, `ops/derivation.md`, and the methodology index resolve, and the session-start hook's count reads a real directory. The decision is indexed in `ops/decisions.md`.
