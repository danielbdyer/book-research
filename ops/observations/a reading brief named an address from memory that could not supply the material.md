# a reading brief named an address from memory that could not supply the material

The reading briefs this round were written in the sharp-questions form, each with a page-level address. One address was wrong. The al-Qushayrī brief named B. R. von Schlegell's *Principles of Sufism* (Mizan, 1990) beside Knysh's translation as a text that could supply the *ḥāl*/*maqām* definitions; the agent established that it is a partial translation of Chapter 3 alone — the forty-three station chapters — and does not contain the terminology chapter where the definitions sit (`archive/reading — al-qushayri, the risala on state and station (knysh 2007).md`). The address had come from memory rather than from a checked table of contents, and nothing in the brief marked it as unverified.

The agent caught it because Knysh was also named and was reachable whole. Had von Schlegell been the only address, the reading would have returned "the chapter does not exist in this translation" and the queue entry would have looked like a failure of the text rather than of the brief. The same round's briefs also carried one paragraph number from memory that was off by one (§335 named as the trail rule; the trail is §334), caught the same way.

What would remove the friction: a reading brief states each address at the grade the vault would accept for a citation — a table of contents checked, or the address marked "from memory, verify first" — under the same rule the notes already obey for quotations. `ops/methodology/sharp questions.md` governs the question; the address has no rule yet.
