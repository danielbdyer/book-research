# a lens refresh that runs before the session's map edits stamps ground that then moves

The `/lens refresh` of 2026-09-02 found twenty-seven expired markers, and the checksum history showed why so many were stamped 2026-08-30: that day's refresh ran inside a session which then ran `/reflect` (reconciling map membership) and grounded the cluster-B remainder, and both moved the maps the fresh stamps rested on. The marker discipline held — nothing was blindly bumped — but the order of work spent a refresh on ground that the same session went on to move, so the next sweep re-expired most of it within the day.

The cost is one redundant reread of twenty-odd sections. What would remove it: run `/lens refresh` (and `/scaffold refresh`) as the last act of a session, after `/reflect` and after any grounding round, so a stamp certifies the session's final state; the skill's own governor already says a refresh follows a stale sweep, and this only adds when in the session the sweep should run.
