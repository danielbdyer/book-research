# the line between a concordance row and a tension note is undrawn

A cold-read audit of the re-authored CLAUDE.md (2026-08-03) surfaced this while answering the question "two drafts disagree about a chapter — what do you do?" The contract's answer is clear as far as it goes: record, never resolve, and the per-chapter comparison costs a row in `ops/chapter concordance.md`. But the routing table also holds "a tension in the book's doctrine → `notes/`, claim with category `tension`," and several existing notes show draft disagreements held as claims rather than rows — the drafts disagree about which person the book speaks in is a tension note; the triad's corner names are a claim; the fifteen-against-twenty-eight scope difference is a claim. No recorded rule says when a disagreement between drafts is bookkeeping (a row) and when it is doctrine (a note), so the sorting currently rides on session judgment.

The working practice, read off the existing cases: a difference between two states of one element is a row; a disagreement that would change what the book *is* — its speaker, its scope, its shape — earns a note. If that is the rule, it costs two sentences in `ops/methodology/` or in CLAUDE.md's Relations section.
