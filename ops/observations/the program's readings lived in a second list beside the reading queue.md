# the program's readings lived in a second list beside the reading queue

The reading queue is the directive's standing first action and the one place a reading is supposed to be queued, in the sharp-questions form, with a Done section that closes it. The practice-model program wrote its thirteen readings into `ops/practice-model ecology — candidate next steps.md` instead — as items A1–A13, each already in the sharp-questions form — because they were produced by a survey and offered to the author for qualifying, not routed through the queue. When the readings ran, seven of the thirteen matched existing queue entries and were marked there; six had none (al-Qushayrī's state and station, Wilber's holarchy and lattice, the seamless mirror, Bhartṛhari, Robbins, Deida), so their closure exists only in a Done entry that summarizes a list the queue never carried, and in a done log added to the next-steps document itself.

The cost is small this round and grows with every program that scopes its own readings: two lists that can drift, and a Done section that no longer indexes what was actually read. What would remove it: a program's readings enter the queue as a tier on the day the program is adopted, with the next-steps document keeping the discussion and pointing at the tier rather than duplicating the entries — the same rule the queue already applies to the forest panel's readings (Tier 6) and the transmission expedition's (Tier 7).
