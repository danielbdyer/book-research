# source — the mythic operating system

Full title: "Firing on All Cylinders: A Mythic Operating System for the Modern Soul." The document opens with a book overview — premise, meta-structure, voice, intended readers — followed by four working titles, a table of contents listing twenty-eight chapters in six parts, and then one chapter written out in full. Chapter 1, "The Braid, The Thread, and The Loom," runs sixteen numbered pages plus an interpolated "Page 4.5," each page carrying its own title. It is written in the first person plural, and it addresses the author directly by name at page 12A. It contains the complete verse text of the poem "Time Is Not Linear," which the later arc places at the heart of its first chapter.

The author's assessment on submission, recorded here as the reason the document was admitted: this edition is a high-water mark of voice, and its table of contents expands the scope and sequence of the work.
